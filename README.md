One picture of food, one ingredient: a single ripe strawberry — glossy, seeded,
droplet-flecked, lit like a studio hero shot on a dark green ground. Bold white
type names it plainly, top and bottom, so the picture reads even at 300 pixels
across: **ONE INGREDIENT — STRAWBERRY**.

## How it works

`main.ts` (Node 22, built-ins only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`, byte for byte, every run. The image itself was
drawn entirely in code for this entry with the Python/PIL script `gen.py` in
this repository — no photograph, no network, no external asset.
